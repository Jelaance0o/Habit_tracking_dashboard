# Habit Tracking Dashboard

A simple and clean **Habit Tracking Dashboard / Daily Planner** built using HTML, CSS, and JavaScript.

The project is designed to help users organize their daily tasks and keep track of their habits through a simple dashboard interface.

## ✨ Features

- 📊 Dashboard interface
- 📝 Daily planner
- ✅ To-Do list
- ➕ Add tasks
- 🗑️ Manage tasks
- 📅 Daily task planning
- 🎨 Clean and modern UI
- 📱 Responsive design
- 🔤 Custom Aeonik font integration
- ⚡ JavaScript-based task functionality

## 🛠️ Technologies Used

- HTML
- CSS3
- JavaScript
- Aeonik Font
